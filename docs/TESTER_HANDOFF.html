1 File journey: register → route → note → decide → direction → evidence ~20–25 min · Roles: speaker → secgen → speaker → specsec → speaker
1
Login as speaker

Register a new internal file

Go to Files → register / new matter. Fill fields using this data:

SubjectUAT-FLOW1 Invitation to Cultural Evening — Protocol advice required
SenderProtocol Wing, National Assembly
BodyThe Protocol Wing requests advice on whether the Honourable Speaker should attend the Cultural Evening on 15 November. Kindly examine seating, security, and political optics, and put up a short recommendation with one attachment if available.
ClassificationINTERNAL
Subject areaProtocol
PriorityNORMAL

Optional: attach any small .txt or .pdf named protocol-note.txt.

You should see: A new diary number (e.g. GOW-2026-xxxxx). File opens with Journey showing Registered.
2
Still speaker

Add a noting para + generate summary

On the same file → Notes tab → add note, then on Overview generate EN summary and Accept.

Note textPara 1: Registered for UAT Flow 1. Please route to Secretary General for examine and advise before Speaker put-up.
You should see: Note numbered on noting sheet; summary accepted timestamp; put-up checklist improves.

Still speaker

Route to Secretary General

On Overview → Route. Choose user Secretary General (secgen).

ProcedureExamine and advise on attendance and protocol
Due date(pick a date 3 days from today)

Or use route template Sec Gen examine if listed.

You should see: Status awaiting receipt; holder = Secretary General; Journey shows route.

Logout → login as secgen

Acknowledge, note, complete procedure

Open the file from Files / Movement / notification. Click Acknowledge, add noting, then Complete procedure.

OutcomeProcedure complete — recommend attendance with VIP seating plan.
You should see: File moves toward decision / Speaker; your noting appears on the sheet.

Logout → login as specsec

Start direction and submit evidence

Open Directions → find your UAT-FLOW1 title → Start → submit evidence.

Evidence textBriefing prepared: recommend attendance; VIP row A; security liaison Protocol Wing. Attachment: seating-draft.txt

Attach a small file (create a text file on your PC if needed).

You should see: Status Evidence submitted (or similar).
7
Logout → login as speaker

Verify evidence and close the file

Directions → verify / approve the evidence. Then open the matter and Close with an outcome.

Close outcomeUAT Flow 1 complete — briefing accepted; attendance confirmed for Cultural Evening.
You should see: Direction closed/verified; matter CLOSED; Journey shows full trail.
