How we work from today

Module-wise cadence — one module at a time until its checks pass.

  1. Pick the next module from the work order below (do not skip core file flow).
  2. Read the module card — routes, roles, features, APIs.
  3. Build / fix only what that module needs.
  4. Test using the checklist on the card (tick boxes — saved in this browser).
  5. Mark status Done / Partial / Todo, then start the next module.
Roles: SPEAKER, SECRETARY_GENERAL, SPECIAL_SECRETARY, DG_IT, ADMIN. DG IT sees Overview + Audit only. MFA off for UAT. Local DB must be UTF8 (not WIN1252) for Urdu summaries — see apps/api/scripts/recreate-utf8-db.js / db:local init flags.
